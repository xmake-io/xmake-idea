An XMake integration plugin for the IntelliJ Platform — configure, build, run, and debug XMake projects without leaving the IDE

Source Code | Discord | Donate | XMake Homepage

Features:
  • xmake
    • C/C++/Objective-C/Swift/Rust/D/Go ... support
    • Cross-platform support
    • More features and info about xmake
  • Create project from the wizard
  • Build profiles with per-profile toolkit, platform, architecture, toolchain, and build mode
  • Build, run, and clean targets
  • Native debugging through CLion debug profiles, or an external DAP driver
  • Compile commands navigation in CLion
  • Menu tools, tool windows, build and run
  • Problems navigation that links back to the source location
Usage instruction:

1. New project
File -> New -> Project -> Select XMake -> Configure the project location, XMake installation, module language, and module type

2. Open existing project
Open -> Select project folder with xmake.lua

3. Build project
Menu -> XMake -> Click 'Build Project'

4. Run Target
Add run configuration -> Select XMake -> Select the target; the active build profile selects the XMake installation
Menu -> XMake -> Click 'Run Target'
