An XMake integration plugin for the IntelliJ Platform

Source Code | Discord | Donate | XMake Homepage

Features:
  • XMake
    • Support for C, C++, Objective-C, Swift, Rust, D, Go, and more
    • Cross-platform support
    • More information about XMake
  • Create projects
  • Project configuration
  • Run configuration
  • Menu tools
  • Tool windows
  • Build and run
  • Navigate to reported errors and warnings
Usage instructions:

1. Create a new project
File -> New -> Project -> Select XMake -> Configure XMake installation, module language, and module type

2. Open an existing project
Open -> Select a project folder containing xmake.lua

3. Build the project
Select Xmake -> Build Project

4. Run a target
Add run configuration -> Select XMake -> Select XMake installation and target
Select Xmake -> Run Target
