A XMake integration plugin in Intellij Platform

Source Code | Discord | Donate | XMake Homepage

Features:
  • xmake
    • C/C++/Objective-C/Swift/Rust/D/Go ... support
    • Cross-platform support
    • More features and info about xmake
  • Create project
  • Project configuration
  • Run configuration
  • Menu tools
  • Tool windows
  • Build and run
  • Goto error and waring problems
Usage instruction:

1. New project
File -> New -> Project -> Select XMake -> Configure XMake installation, module language, and module type

2. Open existing project
Open -> Select project folder with xmake.lua

3. Build project
Menu -> Xmake -> Click 'Build Project'

4. Run Target
Add run configuration -> Select XMake -> Select XMake installation and target
Menu -> Xmake -> Click 'Run Target'
